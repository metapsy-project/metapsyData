# Print variable description

Prints the variable description included in the metadata of an imported
Metapsy database.

## Usage

``` r
# S3 method for variableDescription
print(x, ...)
```

## Arguments

- x:

  A database `data.frame` imported using [`getData()`](getData.md).

- ...:

  Additional arguments.
